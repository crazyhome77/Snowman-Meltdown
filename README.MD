# Mein Schneemann-Spiel (Snowman Meltdown) ☃️🔥

Hallo! Das ist mein erstes richtiges Python-Projekt. Es ist ein Spiel, das so ähnlich funktioniert wie "Galgenmännchen", nur dass hier ein Schneemann in der Sonne schmilzt, wenn man falsche Buchstaben rät.

## Was das Spiel macht
Das Programm wählt ein zufälliges Wort aus einer Liste aus. Du musst versuchen, das Wort Buchstabe für Buchstabe zu erraten.
* Wenn du richtig liegst, wird der Buchstabe im Wort angezeigt.
* Wenn du falsch liegst, schmilzt der Schneemann ein Stück weiter.
* Du gewinnst, wenn du das Wort errätst, bevor der Schneemann ganz weg ist!

## Wie man es spielt
1. Stelle sicher, dass du Python auf deinem Computer hast.
2. Lade die Dateien `game_logic.py` und `ascii_art.py` in einen Ordner.
3. Öffne dein Terminal oder deine Konsole.
4. Starte das Spiel mit dem Befehl:
   ```bash
   python game_logic.py
